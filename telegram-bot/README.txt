# 🌌 WuWa Betting — Telegram Notification Bot

البوت الرسمي لإرسال الإشعارات التلقائية والتنبيهات الحية لمنصة **[WuWa Betting](https://wuwa-betting.netlify.app)**.

مبني ليعمل كخدمة خفيفة ومستقلة يمكن استضافتها وتشغيلها مباشرة على هاتفك عبر تطبيق **Termux**، أو على أي سيرفر سحابي (VPS / Linux / Windows).

---

## 📱 تشغيل واستضافة البوت على Termux (Android)

اتبع هذه الخطوات البسيطة لتشغيل البوت على هاتفك الأندرويد في أقل من 3 دقائق:

### 1. تثبيت Termux وتحديث الحزم
افتح تطبيق Termux واكتب الأوامر التالية:
```bash
pkg update -y && pkg upgrade -y
pkg install git nodejs -y
```

### 2. سحب المشروع والانتقال لمجلد البوت
إذا قمت بسحب مستودع GitHub الخاص بك:
```bash
cd wuwa-betting/telegram-bot
```
أو إذا كنت قد نقلت المجلد مباشرة للهاتف، ادخل إليه:
```bash
cd telegram-bot
```

### 3. تثبيت الاعتماديات
```bash
npm install
```

### 4. إعداد المتغيرات السرية (`.env`)
انسخ ملف الإعداد النموذجي:
```bash
cp .env.example .env
nano .env
```
قم بتعديل القيم التالية:
- `TELEGRAM_BOT_TOKEN`: الرمز الذي حصلت عليه من [@BotFather](https://t.me/BotFather).
- `SUPABASE_URL`: رابط مشروعك في Supabase (`https://axaoxpeqlobiljrromun.supabase.co`).
- `SUPABASE_KEY`: مفتاح Supabase (مفتاح الـ service_role أو مفتاح الـ anon).
- `SITE_URL`: رابط الموقع (`https://wuwa-betting.netlify.app`).

اضغط `CTRL + X` ثم `Y` ثم `Enter` للحفظ والخروج من `nano`.

### 5. تشغيل البوت
```bash
npm start
```
سترى في الشاشة:
```text
✨ [WuWa Bot] Telegram polling daemon started successfully!
🔄 [WuWa Bot] Starting queue worker with interval: 5000ms
```

### 💡 نصيحة: إبقاء البوت يعمل في الخلفية حتى بعد إغلاق Termux
لتشغيل البوت في الخلفية دون أن يتوقف عند إغلاق التطبيق:
1. امنح Termux إذن العمل في الخلفية بدون قيود بطارية:
```bash
termux-wake-lock
```
2. ثبّت مدير المهام `pm2`:
```bash
npm install -g pm2
pm2 start src/bot.js --name "wuwa-bot"
pm2 save
```
لمشاهدة سجلات البوت الحية في أي وقت:
```bash
pm2 logs wuwa-bot
```
لإيقاف البوت:
```bash
pm2 stop wuwa-bot
```

## ⚡ مميزات البوت

1. **إدارة الاشتراكات والتفضيلات التفاعلية**:
   - رسالة ترحيب مخصصة لعالم Solaris.
   - قائمة تفاعلية باللغة العربية تسمح للمشترك بتفعيل أو تعطيل أي فئة إشعارات:
     - 🐉 الزعماء الجدد
     - 🃏 البطاقات الجديدة
     - 🎁 محتويات الصناديق
     - 📦 الصناديق الجديدة
     - ⚔️ النزالات والفعاليات
     - 📢 الإعلانات العامة
   - زر لتفعيل الكل وزر لإيقاف استقبال الإشعارات بضغطة واحدة.
2. **إشعارات تلقائية فورية من قاعدة البيانات**:
   - إشعار فوري عند إضافة زعيم جديد أو بطاقة جديدة أو صندوق جديد أو نزال جديد.
   - إشعار مجمّع عند إضافة بطاقات جديدة إلى صندوق سحب.
3. **أمان عالي ومعدل إرسال آمن (Rate Limiting)**:
   - إرسال على دفعات آمنة (25 رسالة في الثانية) لتفادي أخطاء 429 في Telegram.
   - التعرف التلقائي على المستخدمين الذين قاموا بحظر البوت وتحديث حالتهم لمنع إهدار الموارد.
   - دعم إرسال الصور وروابط الأزرار المباشرة لصفحات الموقع.
